### 1.14 R11：压脚

- 两针板机型 ==钢丝压脚（5工位）==：

![[image1093.png]]

用一个两位数AB来表示编织系统和翻针系统的压脚状态。

十位数（A=1、2、5）表示编织系统的毛刷和压脚状态

个位数（B=3、4）表示翻针系统的毛刷和压脚状态

==可以设置的范围：13、14、23、24、53、54，旧版已失效指令报错，其他数值都会当成54处理==

==注：无压脚、埋纱压脚时，功能线也显示此处内容==

GK4手套机五工位压脚位置3和4兼容有问题时，可以制版选择三工位压脚编译上机

- 两针板机型 ==钢丝压脚（5工位）粗针==

  ![[image1094.png]]

  可设置11~15、21~25、31~35、41~45、51~55，其它指令视为无效并视为55编译处理

- 两针板机型 ==3====工位压脚==：

==可以设置的范围：11、15、51、55，其它指令视为无效并视为55编译处理==

![[image1095.png]]

- 四针板机型：

四针板的机器，压脚的结构跟两针板机器有所不同。以下是四针板机器压脚的详细信息：

1.  只有左右系统装备有压脚，中系统没有压脚。

2.  压脚和毛刷是独立工作的。（不同于两针板机器的5工位压脚。）

3.  压脚有两个不同的状态。工作位置，不工作位置。

4.  对同一个系统，如果压脚和沉降片同时工作，压脚和沉降片可能会干涉。

5.  通常情况下，上针板到下针板的翻针要使用压脚，其他情况一般不用压脚。

> 基于以上信息，我们使用不同于两针板机器的另外一套功能线指令。
>
> ==R11上指定一个两位数“AB”来控制压脚。==
>
> ==十位数“A”用来定义编织系统的压脚。==
>
> ==个位数“B”用来定义翻针系统的压脚。==
>
> A的范围是：1或5。
>
> B的范围是：1，2，5。
>
> 1=压脚工作
>
> 2=上翻下时压脚工作
>
> 5=压脚不工作
>
> 经过排列组合，R11上一共有6个有效指令。（11,12,15,51,52,55）
>
> R11上的其他指令都视为无效数据，并且编译时无效数据都视为52进行编译。


| R11 | 执行的结果 |
| ---- | ---- |
| 11 | 编织系统压脚工作，翻针系统压脚工作 |
| 12 | 编织系统压脚工作，上翻下时压脚工作 |
| 15 | 编织系统压脚工作，翻针系统压脚不工作 |
| 51 | 编织系统压脚不工作，翻针系统压脚工作 |
| 52 | 编织系统压脚不工作，上翻下时压脚工作 |
| 55 | 编织系统压脚不工作，翻针系统压脚不工作 |
| 其他 | 视为52进行编译 |


如果中系统指定了压脚指令，自动忽略掉。

为了避免机器上出现冲突，如果某个系统的压脚工作，我们应该自动让这个系统的沉降片不工作。现在这个处理是由恒强机器系统自动处理的，机器系统检测到压脚工作，对应的沉降片使用第6段的设置。
